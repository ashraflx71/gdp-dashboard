## 🚀 عن المشروع
هذا المستودع يجمع بين طموح **الاستدامة الرقمية** وأدوات **الذكاء الاصطناعي**:
1. **دليل البرمجيات الخضراء:** قائمة بأهم الأدوات لتقليل الانبعاثات الكربونية للبرامج.
2. **محول LaTeX:** أداة ذكية لتحويل صور المعادلات الرياضية إلى أكواد LaTeX برمجية.

## 🛠️ الأدوات المستخدمة
* **Streamlit:** لواجهة المستخدم.
* **Pix2Tex:** لمحرك الذكاء الاصطناعي.
* **Python:** لغة البرمجة الأساسية.
